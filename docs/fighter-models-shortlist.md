# Fighter models: free shortlist

Decision: Mixamo is in use, so the licence record at the end is the current list. The rest of this file is kept for reference.

Checked on 2026-11-06. Check each page again before downloading, because terms can change. Nothing here has been downloaded or tried in the game yet.

## Recommended: Quaternius (one shared skeleton)

This is the best fit found. It may remove most of the Mixamo work, because the characters and sword animations already share a skeleton.

| Pack | What it gives | Licence | Formats | Link |
|---|---|---|---|---|
| Universal Base Characters | 6 bodies (Superhero, Regular, Teen; male and female) and 20 hairstyles | CC0 | glTF, FBX, OBJ | https://quaternius.com/packs/universalbasecharacters.html |
| Universal Animation Library 2 | Melee and armed combos, 3 and 4 hit combos split into hits and recoveries | CC0 | GLB, FBX | https://quaternius.com/packs/universalanimationlibrary2.html |
| Universal Animation Library | Locomotion in 8 directions, jog, sprint, deaths | CC0 | Check the pack | https://quaternius.com/packs/universalanimationlibrary.html |

Only about 60 to 70% of each pack is free; the rest is in the paid Source version. Check that the free part includes the sword combos.

These bodies are stylised rather than true anime. With our toon shader, outlines, hair and colours they should read as anime-inspired.

Avoid the "free" anime models on CGTrader and similar stores for now. They are royalty-free rather than CC0, and many restrict redistribution, which is what a web game does when it serves the file.

## Mixamo

Use it for any model that isn't on the Quaternius skeleton. Adobe's FAQ, as quoted on its community forum, allows characters and animations in games without credit, but not giving out the raw files. A web game does serve those files to players' browsers, so read Adobe's current terms before going public. I could only find forum copies, not the terms themselves.

Forum sources: https://community.adobe.com/t5/mixamo-discussions/mixamo-faq-licensing-royalties-ownership-eula-and-tos/td-p/13234775
